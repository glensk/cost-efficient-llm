# Best practices for cost-efficient LLM use

Slides of a 15-minute talk at the Swiss Data Science Center (SDSC), 2026-11-20:
<https://glensk.github.io/cost-efficient-llm/>

Open `index.html` in a browser. Right/Space reveals the next step, Left goes back,
`A` shows all steps of a slide, `N` shows the speaker notes with the source of every number.
The deck works offline (KaTeX is vendored in `vendor/`).

`scripts/relay_cost_stats.py -h` recomputes the token and relay numbers from a per-session
usage export (`-f <file>` or `-u <url>`).

Previous talk: <https://glensk.github.io/coding-agents-talk/>
